# Cyber Security

ACI's security practice covers DevSecOps, security observability, identity and access
management, compliance preparation, vulnerability management, cloud security posture,
and ongoing security operations.

The service page describes integrating automated security scans and vulnerability checks
into CI/CD so that development teams receive early feedback. Identity work includes
zero-trust architecture, single sign-on, multi-factor authentication, and privileged
access management. Cloud security work includes visibility, configuration monitoring,
workload protection, and compliance checks across AWS, Azure, and Google Cloud.

ACI says its managed security operations provide 24/7 Tier 1 through Tier 3 analyst
coverage, weekly threat hunting, incident-response playbooks, and audit evidence aligned
with obligations such as SOC 2, ISO 27001, HIPAA, and PCI-DSS. Listed monitoring and
response platforms include LogRhythm, Splunk, Microsoft Sentinel, CrowdStrike, and
PagerDuty.

The page positions security as a continuous operational responsibility. The same
engineering capability may design controls, integrate them into delivery pipelines, and
operate monitoring after deployment. Its stated approach is to integrate with an
enterprise's existing security tools rather than require replacement of every platform.
